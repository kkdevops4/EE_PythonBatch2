## 📖 Project Description

Task Manager is a Python-based command-line application designed to help users organize and manage daily tasks efficiently. Users can create tasks, assign priorities, specify due dates, mark tasks as completed, and filter tasks based on their completion status. The project demonstrates the use of Python data structures, functions, conditional statements, and menu-driven programming.

---

## 🎯 Objectives

- Organize daily tasks efficiently.
- Assign priorities to tasks.
- Track task completion status.
- Display pending and completed tasks separately.
- Improve productivity using a simple command-line interface.

---

## ✨ Features

- ➕ Add new tasks
- 🔥 Assign task priority (High, Medium, Low)
- 📅 Set due dates for tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- ⏳ View pending tasks
- ✔️ View completed tasks
- 🖥️ User-friendly menu-driven interface
