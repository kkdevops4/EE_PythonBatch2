# Vehicle Information Text File Writer

## Description

This project demonstrates Python File Handling by reading vehicle records from a text file, appending a new vehicle record, and displaying the updated records.

## Features

- Read vehicle records
- Append a new vehicle record
- Display updated records

## Concepts Used

- File Handling
- open()
- read()
- write()
- close()
- Read Mode ("r")
- Append Mode ("a")

## Files

- `main.py` - Python program
- `vehicles.txt` - Stores vehicle records
