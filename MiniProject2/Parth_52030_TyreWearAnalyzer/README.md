## 📖 Project Description

Tyre Wear Analyzer is a Python-based console application that simulates tyre sensor readings, stores the generated data, analyzes tyre wear conditions, determines severity levels, and generates a detailed report. The project demonstrates modular programming, data processing, JSON handling, and automated report generation.

---

## 🎯 Objectives

- Simulate tyre sensor readings.
- Store generated data in JSON format.
- Analyze tyre wear conditions.
- Determine tyre severity.
- Generate and save analysis reports.

---

## ✨ Features

- Generate random tyre sensor data
- Store sensor readings in JSON
- Analyze tyre wear conditions
- Sort analysed tyre data
- Detect tyre severity level
- Generate readable tyre reports
- Save reports to text files
- Modular project structure
